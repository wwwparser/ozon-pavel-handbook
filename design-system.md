# Оформление учебника

Тип: редакционный учебный сайт. Светлый бумажный фон #f7f5ef, текст #202d31, акцент #176653, границы #d8ded8. Заголовки Georgia; основной текст системный Segoe UI. Статья шириной до 75 знаков, фиксированное оглавление на широком экране, сворачиваемое на узком. Шкала отступов 8/16/24/32/48. Размер текста 18, вторичный 14, заголовки 28/36. Таблицы прокручиваются внутри своего блока. Интерактивные поля подписаны, ошибки показываются рядом с расчётом.
