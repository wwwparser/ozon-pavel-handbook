# Практика продавца Ozon — учебник

[Открыть сайт](https://wwwparser.github.io/ozon-pavel-handbook/) · [Локальный HTML](docs/index.html) · [Оглавление Markdown](book/00-vvedenie.md)

Учебник по открытым материалам [Telegram](https://t.me/prodavecpavel) и [YouTube](https://www.youtube.com/@prodavec_pavel) «Продавец Павел». Редакция от 8 октября 2026 года. Смысловая редактура, объяснения и код выполнены Codex; это самостоятельная переработка, не официальное издание Ozon или автора канала.

Учтены все 72 доступных Telegram-сообщения, прочитаны 62 текста и просмотрены 27 фото. Все 24 видео канала — 20 обычных и четыре Shorts — скачаны для обработки и полностью расшифрованы локально GigaAM. Содержание распределено по главам; отдельно доступны транскрипты с таймкодами и ссылки на исходные видео. Четыре Excel разобраны по ячейкам и формулам.

Сайт содержит учебные главы, практикум с ответами, карточки повторения, реестры источников и шесть расчётных моделей: четыре из Excel, закупку из Китая и результат магазина за период. Значения можно менять в браузере; расчёт по Excel экспортируется в CSV. Исходные таблицы скачиваются с сайта. HTML работает и локально без сервера.

В новых Excel Ozon обнаружено исключение рекламы из расчёта прибыли. Калькулятор показывает исходный результат и результат с рекламой. Например, в модели от 301 ₽ пример даёт около 179,99 ₽ по Excel и 114,99 ₽ после вычета рекламы 10%. Контрольные расчёты воспроизводят первую заполненную строку каждого из четырёх файлов.

Тарифы исторические и редактируются вручную. Автоматическое распознавание иногда искажает числа и названия; весь видеоряд покадрово не проверен. Алгоритмические гипотезы, прогнозы дохода и рекламные обещания обозначены отдельно. Новости о налогах и документах не превращены в действующие правовые инструкции.

## Варианты реализации из IDEA.md

| Вариант | Стек и результат | Оценка | Приоритет |
|---|---|---|---|
| Статический учебник | Telethon, yt-dlp, GigaAM → JSON/Markdown → Python-Markdown; HTML/CSS/JavaScript; GitHub Pages | 4–8 часов на основу; 1–3 рабочих дня на обработку видео и редактуру | Реализован |
| Издание для скачивания | Те же главы + Pandoc, EPUB/PDF, корректура и вёрстка | 2–4 рабочих дня после содержания | Следующий вариант |
| Обновляемая база | SQLite, FastAPI, поиск, журнал новых источников и редакторское утверждение | 4–7 рабочих дней и регулярная редактура | При постоянном обновлении |

Оценки — ориентиры для одного исполнителя, не фактический учёт времени. Статический сайт выбран для простого чтения на GitHub Pages, автономной работы калькуляторов и отсутствия серверных расходов.

## Основные ограничения

| Риск | Как обработан |
|---|---|
| Меняются комиссии и интерфейс | Тарифы обозначены как исторические; все ставки доступны для ручной замены |
| Формулы пропускают расходы | Разобраны базы расчёта, двойной учёт и пропуск рекламы; исходный результат сохранён для сравнения |
| Заказы принимают за прибыль | Отдельно объяснены заказы, выкуп, начисления, баланс и расходы; разобраны скриншоты |
| Неполнота источника | Удалённые, закрытые и будущие публикации не входят в снимок; список источников зафиксирован |
| Ошибки ASR и рекламные утверждения | Транскрипты помечены; непроверяемые суммы и гипотезы не выдаются за установленные факты |
| Секреты и доступы | `.env`, Telegram-сессии, cookies и сырые данные исключены из Git; сайт не требует API-ключей |

## Сборка и проверка

Для повторной сборки из репозитория нужен Python с `Markdown` и Node.js для проверок расчётов. Публичные снимки и транскрипты сохранены; доступ к Telegram не требуется.

```powershell
python -m pip install -r requirements.txt
python scripts/build.py
python scripts/verify.py
```

Для нового снимка Telegram заполните `.env` по `.env.example`, указав свою авторизованную сессию. Скрипты не создают авторизацию автоматически.

```powershell
python scripts/export_channel.py
python scripts/download_tables.py
python scripts/download_photos.py
python scripts/analyze_tables.py
python scripts/prepare_calculators.py
```

Обработка YouTube реализована в `youtube_inventory.py`, `fetch_youtube_all.py` и `transcribe_all.py`. Дополнительно нужны yt-dlp, ffmpeg/ffprobe, PyTorch и GigaAM. Загрузка в текущем окружении использует локальный прокси и Browser Bridge для обновления cookies; настройки следует адаптировать к своей машине. Cookies сохраняются вне проекта и не публикуются. Аудио не входит в сайт.

```powershell
python scripts/youtube_inventory.py
python scripts/fetch_youtube_all.py
python scripts/transcribe_all.py
python scripts/audit_transcripts.py
```

После обновления источников **вручную** прочитайте новые материалы, измените главы и карту использования в `scripts/build.py`, затем пересоберите. Скрипт сборки не пишет учебный текст за редактора. GitHub Pages публикует каталог `/docs` ветки `main`.
